## 数据库

| 数据库 | 用途 | 字符集 |
|--------|------|--------|
| `flowable` | Flowable 引擎表 (ACT_*/FLW_*) | utf8mb4_general_ci |
| `user_center` | 业务表 (sys_*/process_config) | utf8mb4_general_ci |

**user_center 表结构：**

| 表 | 说明 |
|---|------|
| sys_user | 用户表（BCrypt 密码） |
| sys_department | 部门表（树形 parent_id） |
| sys_role | 角色表 |
| sys_user_role | 用户-角色关联 |
| sys_menu | 菜单/按钮权限表 |
| sys_role_menu | 角色-菜单关联 |
| process_config | 流程发布配置（任务处理人、发布状态） |

## 认证鉴权

- **登录**：`POST /api/auth/login` → 返回 32 位 Token + SessionUser（含 menus + permissions）
- **鉴权**：`AuthInterceptor` 拦截 `/api/**`，验证 `Authorization: Bearer <token>`
- **滑动窗口**：2h 过期，剩余 < 30min 时自动续约 2h
- **RBAC**：用户 → 角色 → 菜单权限，前端导航动态渲染
- **默认密码**：所有用户 `123456`（BCrypt 加密）

## 部署

```bash
# 全部启动
docker compose up -d

# 单独构建
docker compose build --no-cache user-center
```
